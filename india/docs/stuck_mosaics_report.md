- **416** celulas-anos passaram pelo processo de travamento/cancelamento.
- **49** celulas unicas afetadas.

## Observacao importante

A contagem de granulos das celulas canceladas varia de **2 a 299**. Isso mostra que o travamento NAO e um problema unico de "muitos granulos":

1. **Celulas densas (>=200 granulos, ~46):** provavel `User memory limit exceeded` ao montar o grafo (diagnostico em `NG-43-X-D_2017`, 250 granulos).
2. **Celulas com poucos granulos (<200, ~370):** em grande parte a regiao `NF-*` (nordeste), que tambem travou (ex.: `NF-45-X-D_1988` ficou ~47 h com ~38 granulos). Causa ainda nao identificada.

## Plano de resolucao

- Teste em andamento: `shardSize=32` em `NG-43-X-D_2017`.
  - Se resolver -> relancar as faltantes com `shard_size` reduzido.
  - Se nao resolver -> usar `SCENE_CLOUD_MAX < 60` (reduzir granulos).
- Apos os testes: relancar TODAS as faltantes (incluindo as de granulos baixos), garantindo que toda tarefa rode ao menos 1x.
